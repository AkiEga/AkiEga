### Tools I've Built

#### VS Code Extensions
- [file-open-history](https://github.com/AkiEga/file-open-history) — A VS Code extension that tracks and displays your file-opening history in a text editor or output channel
- [vscode-extension-ascii-sketch](https://github.com/AkiEga/vscode-extension-ascii-sketch) — A VS Code extension for creating and editing ASCII art in `.ascii` files with canvas generation, box drawing, and alignment tools
- [vscode-extension-section-info](https://github.com/AkiEga/vscode-extension-section-info) — A VS Code extension that copies selected code sections with metadata (file path, line, git info, function name) to the clipboard
- [vscode-extension-svg-sketch](https://github.com/AkiEga/vscode-extension-svg-sketch) — A VS Code extension that lets you create and edit SVG diagrams using a canvas-based editor with shapes, arrows, text, and more
- [vscode-extension-tree](https://github.com/AkiEga/vscode-extension-tree) — Visualizes folder structures in VS Code by running the `tree` command from the Explorer sidebar and displaying results in an editor or webview
- [vscode-msvs-proj-manager](https://github.com/AkiEga/vscode-msvs-proj-manager) — A VS Code extension for managing Microsoft Visual Studio solution files by parsing `.sln` files and opening terminals in project root directories
#### Embedded Systems / Hardware
- [pico_arcade_controller](https://github.com/AkiEga/pico_arcade_controller) — Arcade joystick controller built with Raspberry Pi Pico (USB HID). Supports mouse cursor movement, long-press acceleration, and window switching via rapid left/right inputs.
- [ega-right-kb](https://github.com/AkiEga/ega-right-kb) — Custom right-side keyboard powered by Raspberry Pi Pico with GPIO key mapping and HID support.
