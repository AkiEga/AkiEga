### Tools I've Built

#### VS Code Extensions
- [file-open-history](https://github.com/AkiEga/file-open-history) — Tracks and displays the history of files opened in VS Code
- [vscode-extension-ascii-sketch](https://github.com/AkiEga/vscode-extension-ascii-sketch) — A VS Code extension for creating and editing ASCII art with dedicated language support and drawing tools
- [vscode-extension-section-info](https://github.com/AkiEga/vscode-extension-section-info) — Copy selected code with context information to clipboard in customizable formats
- [vscode-extension-svg-sketch](https://github.com/AkiEga/vscode-extension-svg-sketch) — Create and edit SVG diagrams with a canvas-based editor in VS Code
- [vscode-extension-tree](https://github.com/AkiEga/vscode-extension-tree) — Display folder directory structures in VS Code using the tree command
- [vscode-msvs-proj-manager](https://github.com/AkiEga/vscode-msvs-proj-manager) — Manage Microsoft Visual Studio solutions in VS Code with .sln file parsing and terminal integration
#### Embedded Systems / Hardware
- [pico_arcade_controller](https://github.com/AkiEga/pico_arcade_controller) — Arcade joystick controller built with Raspberry Pi Pico (USB HID). Supports mouse cursor movement, long-press acceleration, and window switching via rapid left/right inputs.
- [ega-right-kb](https://github.com/AkiEga/ega-right-kb) — Custom right-side keyboard powered by Raspberry Pi Pico with GPIO key mapping and HID support.
