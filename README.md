### Tools I've Built

#### VS Code Extensions
- [file-open-history](https://github.com/AkiEga/file-open-history) — Tracks and displays the history of files opened in VS Code
- [vscode-extension-ascii-sketch](https://github.com/AkiEga/vscode-extension-ascii-sketch) — VS Code extension for creating ASCII art with canvas generation, box drawing, and alignment tools
- [vscode-extension-section-info](https://github.com/AkiEga/vscode-extension-section-info) — Copies selected code with file path, line numbers, and git info in customizable formats
- [vscode-extension-svg-sketch](https://github.com/AkiEga/vscode-extension-svg-sketch) — Create and edit SVG diagrams with a canvas-based editor in VS Code
- [vscode-extension-tree](https://github.com/AkiEga/vscode-extension-tree) — Right-click any folder in VS Code to generate and view tree command output
- [vscode-msvs-proj-manager](https://github.com/AkiEga/vscode-msvs-proj-manager) — Parses Visual Studio solution files and opens project terminals in VS Code
#### Embedded Systems / Hardware
- [pico_arcade_controller](https://github.com/AkiEga/pico_arcade_controller) — Arcade joystick controller built with Raspberry Pi Pico (USB HID). Supports mouse cursor movement, long-press acceleration, and window switching via rapid left/right inputs.
- [ega-right-kb](https://github.com/AkiEga/ega-right-kb) — Custom right-side keyboard powered by Raspberry Pi Pico with GPIO key mapping and HID support.
