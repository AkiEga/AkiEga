### Tools I've Built

#### VS Code Extensions
- [file-open-history](https://github.com/AkiEga/file-open-history) — Tracks and displays your file opening history in VS Code
- [vscode-extension-ascii-sketch](https://github.com/AkiEga/vscode-extension-ascii-sketch) — A VS Code extension for creating and editing ASCII art with canvas, box drawing, and alignment tools
- [vscode-extension-section-info](https://github.com/AkiEga/vscode-extension-section-info) — Copies selected code sections and related file, line, and Git details to the clipboard in custom formats
- [vscode-extension-svg-sketch](https://github.com/AkiEga/vscode-extension-svg-sketch) — A VS Code extension for drawing and editing SVG diagrams in a canvas editor with keyboard-friendly tools
- [vscode-extension-tree](https://github.com/AkiEga/vscode-extension-tree) — Shows a folder's tree command output in VS Code as text or in a side by side webview
- [vscode-msvs-proj-manager](https://github.com/AkiEga/vscode-msvs-proj-manager) — VS Code extension to parse Visual Studio solution files and open terminals in project root folders
#### Embedded Systems / Hardware
- [pico_arcade_controller](https://github.com/AkiEga/pico_arcade_controller) — Arcade joystick controller built with Raspberry Pi Pico (USB HID). Supports mouse cursor movement, long-press acceleration, and window switching via rapid left/right inputs.
- [ega-right-kb](https://github.com/AkiEga/ega-right-kb) — Custom right-side keyboard powered by Raspberry Pi Pico with GPIO key mapping and HID support.
