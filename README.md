### Tools I've Built

#### VS Code Extensions
- [file-open-history](https://github.com/AkiEga/file-open-history) — Tracks and displays a history of file-opening actions in VS Code via a text editor panel or output channel
- [vscode-extension-ascii-sketch](https://github.com/AkiEga/vscode-extension-ascii-sketch) — A VS Code extension for creating and editing ASCII art with canvas generation, smart box drawing, and `.ascii` file support
- [vscode-extension-section-info](https://github.com/AkiEga/vscode-extension-section-info) — A VS Code extension that copies selected code sections to the clipboard with customizable metadata such as file path, line number, git info, and language
- [vscode-extension-svg-sketch](https://github.com/AkiEga/vscode-extension-svg-sketch) — A VS Code extension that provides a canvas-based editor for creating and editing SVG diagrams with shapes, arrows, text, and templates
- [vscode-extension-tree](https://github.com/AkiEga/vscode-extension-tree) — Visualizes folder structures in VS Code by running the `tree` command from the Explorer sidebar and displaying results in an editor
- [vscode-msvs-proj-manager](https://github.com/AkiEga/vscode-msvs-proj-manager) — A VS Code extension that parses Visual Studio solution files and lets you open terminals in project root directories
#### Embedded Systems / Hardware
- [pico_arcade_controller](https://github.com/AkiEga/pico_arcade_controller) — Arcade joystick controller built with Raspberry Pi Pico (USB HID). Supports mouse cursor movement, long-press acceleration, and window switching via rapid left/right inputs.
- [ega-right-kb](https://github.com/AkiEga/ega-right-kb) — Custom right-side keyboard powered by Raspberry Pi Pico with GPIO key mapping and HID support.
