### Tools I've Built

#### VS Code Extensions
- [file-open-history](https://github.com/AkiEga/file-open-history) — Tracks and displays the history of files you've opened in VS Code
- [vscode-extension-ascii-sketch](https://github.com/AkiEga/vscode-extension-ascii-sketch) — A VS Code extension for easily creating and editing ASCII art with tools for canvas and smart box generation.
- [vscode-extension-section-info](https://github.com/AkiEga/vscode-extension-section-info) — Copy selected code sections with file, line, and git context to clipboard in customizable formats
- [vscode-extension-svg-sketch](https://github.com/AkiEga/vscode-extension-svg-sketch) — Create and edit SVG diagrams with a canvas-based editor in VS Code
- [vscode-extension-tree](https://github.com/AkiEga/vscode-extension-tree) — VS Code extension that displays folder structure as tree output via right-click context menu
- [vscode-msvs-proj-manager](https://github.com/AkiEga/vscode-msvs-proj-manager) — VS Code extension for parsing Visual Studio solutions and opening terminals in project directories
#### Embedded Systems / Hardware
- [pico_arcade_controller](https://github.com/AkiEga/pico_arcade_controller) — Arcade joystick controller built with Raspberry Pi Pico (USB HID). Supports mouse cursor movement, long-press acceleration, and window switching via rapid left/right inputs.
- [ega-right-kb](https://github.com/AkiEga/ega-right-kb) — Custom right-side keyboard powered by Raspberry Pi Pico with GPIO key mapping and HID support.
